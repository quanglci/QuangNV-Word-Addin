# QuangNV GitHub OTA – thử nghiệm an toàn 2026.11.21.2

Đây là **luồng thử nghiệm riêng**, không phải phiên bản phát hành chính thức cho Microsoft Word.

- [feed.csv](./feed.csv): thông tin phiên bản và chữ ký RSA kiểm thử.
- [quangnv_ota_sandbox_2026.11.21.2.txt](./quangnv_ota_sandbox_2026.11.21.2.txt): dữ liệu **văn bản thuần**, không chứa macro hoặc chương trình.
- Công cụ chạy trên Windows được cung cấp riêng trong cuộc trò chuyện, chỉ ghi vào `%LOCALAPPDATA%\QuangNV\OTA_SandboxTest`.
- Dùng để thử tải HTTPS, xác thực chữ ký, SHA-256, sao lưu/thay thế/khôi phục.
- **Không thay thế Word Add-in đang cài** và **không kích hoạt bản phát hành trong bảng OTA_AnToan**.

Tệp `.dotm` dự kiến cho OTA thực tế đã bị Google Drive cảnh báo. Không đưa nó vào kho công khai hoặc phát hành cho nhiều máy trước khi phân tích mã VBA và có kết quả kiểm tra bảo mật phù hợp.
