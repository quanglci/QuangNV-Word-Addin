# QuangNV – Word Add-in

Kho quản lý các phiên bản phát hành cho Microsoft Word Add-in QuangNV.

## Trạng thái OTA
- Bản nền đã cài thử: **2026.11.21.1**.
- Bản thử OTA dự kiến: **2026.11.21.2** (chưa phát hành).
- Lịch kiểm tra tự động trên máy đã cài: mỗi **2 giờ**, khi tài khoản Windows hoạt động.
- Chỉ cập nhật sau khi người dùng chấp thuận, xác minh SHA-256 và chữ ký; sao lưu và khôi phục nếu thất bại.

## An toàn và kiểm thử
- **Chưa có bản cập nhật công khai ở GitHub Releases.**
- Tệp Add-in `.dotm` đã từng bị Google Drive chặn với thông báo nghi ngờ malware/spam. Phải kiểm tra tệp VBA và quét bảo mật độc lập trước khi phát hành qua GitHub. Chuyển máy chủ **không** đồng nghĩa tệp đã an toàn.
- Không đăng khóa ký riêng, API Key AI hoặc dữ liệu cá nhân lên kho công khai.

## Phát hành
Xem các bản phát hành tại [GitHub Releases](../../releases). Các máy đang dùng bản nền tiếp tục hoạt động bình thường cho đến khi có bản phát hành được kiểm thử và kích hoạt.
